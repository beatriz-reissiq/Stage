# Sobre o projeto

O Stage é uma plataforma desenvolvida para incentivar pessoas que desejam desenvolver suas habilidades musicais e superar a insegurança de se apresentar.

A aplicação reúne conteúdos, dicas e recursos para auxiliar iniciantes no desenvolvimento musical, proporcionando um espaço para aprendizado e troca de experiências. A plataforma também conta com um quiz que identifica o perfil e os interesses do usuário, direcionando-o para conteúdos e recursos mais adequados às suas necessidades.

---

# Funcionalidades

* Cadastro e login de usuários;
* Dashboard personalizada;
* Hub de conteúdos sobre música e desenvolvimento pessoal;
* Compartilhamento de experiências;
* Dicas para iniciantes em canto e instrumentos;
* Área de ajuda com indicações de plataformas e materiais de estudo;
* Conteúdos sobre confiança e preparação para apresentações.

# ⚙️ Como usar

### 1. Clone este repositório em sua máquina

```bash
git clone <URL_DO_REPOSITORIO>
```

### 2. Crie as tabelas necessárias no Banco de Dados

Siga as instruções presentes no arquivo:

```text
/src/database/script-tabelas.sql
```

### 3. Configure o ambiente da aplicação

Atualize o arquivo `.env.example` para `.env` e adicione as credenciais necessárias para a conexão com o banco de dados.

### 4. Instale as dependências

No terminal, execute:

```bash
npm i
```

Este comando instalará todas as bibliotecas necessárias para a execução do projeto, listadas no arquivo `package.json`.

Ao final da instalação, será criada automaticamente a pasta:

```text
node_modules
```

que contém as dependências utilizadas pela aplicação.

### 5. Inicie a aplicação

Execute:

```bash
npm start
```

A aplicação será iniciada conforme a configuração realizada anteriormente.

### 6. Acesse o projeto

Após a inicialização, abra em seu navegador o endereço informado no terminal.

### 7. Encerrar a execução

Para interromper a aplicação, pressione:

```text
CTRL + C
```

no terminal em que ela estiver sendo executada.
